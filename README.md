# Information Graphics Website

## Files
- `index.html` — website structure and content
- `css/style.css` — layout, typography, 12-column grid and styling
- `js/script.js` — press `G` to toggle the grid overlay

## Grid setup
The layout is built with CSS Grid:

- 12 columns
- 50px gutters on the main desktop design
- 70px outer margins
- Designed around a 16:9 desktop canvas
- The column widths are fluid so the site can adapt to browser width

At approximately 1890px content width:
- 12 × 100px columns
- 11 × 50px gutters
- 70px margins on both sides

Total design width = 1890px.

## How to edit
1. Open the `information-graphics-website` folder in Visual Studio Code.
2. Open `index.html`.
3. If you use the Live Server extension, right-click `index.html` and choose **Open with Live Server**.
4. Edit the text and styles as needed.

The pink grid is intentionally included as an editing overlay. Press `G` in the browser to hide or show it.
